training, paid service, credentials, native phone action or publication involved.
This is a public-image engineering diagnostic, not representative real-camera
or independent human acceptance. Model pretraining membership remains unknown.

against every third-party right or privacy concern.

## Reproduction

Read the model protocol first. Acquisition is explicit and never invokes models:

```sh
node scripts/qa/local-vision/spatial-data-corpus.mjs --acquire work/FRESH/candidates
node scripts/qa/local-vision/spatial-data-corpus.mjs --freeze \
  work/FRESH/candidates/fixtures.json scripts/qa/local-vision/spatial-data-review.json \
  work/FRESH/final-reviewed
```

Use a fresh existing parent under `work/`; outputs refuse overwrite. Source pages
and licences may change: reacquisition must fail closed on licence drift rather
than silently substituting a new label or image. Exact old image bytes require
their retained local receipt. No API fetch occurs in ordinary unit validation.
