# Project charter

## Mission

Build KierrätysAppi, an Android-first, cross-platform Finnish application that turns a scanned or entered GTIN into component-specific, source-backed Finnish packaging sorting guidance and safely guides users when evidence is missing.

## Value proposition

**Skannaa, kuvaa tai hae tuote – KierrätysAppi kertoo, miten pakkauksen jokainen osa lajitellaan.**

## Principles

1. Accuracy and calibrated uncertainty before breadth.
2. No account required for basic scanning.
3. Product data and jurisdictional sorting policy remain replaceable and independently versioned.
4. Privacy-conscious local behavior is the default.
5. Finnish-first content with an English localization architecture.
6. The first release earns trust through transparent source, date, verification, and confidence information.

## Initial success outcome

A user can grant camera access contextually, scan or type a valid GTIN, receive a normalized Open Food Facts lookup through KierrätysAppi's application service, and see safe component guidance or an honest missing/unknown flow.
